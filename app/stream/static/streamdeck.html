Ready-made profile

One file with every key set up: pictures, addresses and GET request in background already ticked.

  1. Double-click MTG Stream.streamDeckProfile: the Stream Deck software opens and adds it.
  2. Pick the profile MTG Stream. Done.

Saved a new preset? Download the profile again to get it on a key.

One key at a time

No plugin needed: the Website action of the Stream Deck software does it.

  1. Drag Website (under System) onto a key.
  2. Click a key above, press Copy address and paste it into URL.
  3. Tick GET request in background, so no browser window opens.
  4. Download picture, then click the key picture > Set from file. Leave the title empty.
