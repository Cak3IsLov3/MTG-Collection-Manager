Setting up a key (no plugin needed)

  1. In the Stream Deck software, drag Website (under System) onto a key.
  2. Click a key below and press Copy address; paste it into URL.
  3. Tick GET request in background, so no browser window opens.
  4. Press Download picture, then click the key's picture in the Stream Deck software > Set from file. Leave the title empty: the name is on the picture.

The app has to be running. The keys only work from your Stream Deck or this computer, not from other websites.
